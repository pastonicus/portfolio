# Portfolio Static Site

This folder contains a static portfolio/site experience built with vanilla HTML, CSS and JavaScript.

## Local development

No package install is required for the static page itself. To preview locally, serve the folder with any static HTTP server:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Optional CMS admin

A Netlify CMS admin shell is available at:

- <http://localhost:8000/admin/>

The CMS config is stored in [admin/config.yml](admin/config.yml) and content examples are stored under [content](content).
